## Core Direction

- Vite + plain JavaScript frontend
- Supabase Auth/Postgres/Realtime/Storage backend
- Netlify hosting
- DM account required
- Players join as guests with link/code
- Campaign-saved characters with character-specific rejoin codes
- DM God screen and player screens
- Realtime battle map
- Fog of war and fog areas
- Freeform terrain
- Hazards, traps, and difficult terrain
- Glowing movement paths with Finalize Move
- Expanded testing before final testing release
